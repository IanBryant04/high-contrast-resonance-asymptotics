# High-Contrast Resonance and Inverse Design

My undergraduate research on resonance in multilayer nanoparticles
and the inverse problem of finding model parameters for a desired response.

This repository contains MATLAB modeling and inverse-design code,
validation work, research results, and related Python and neural-network
experiments.

## Code and results

This repository includes double- and three-layer models, inverse-design
scripts, and validation work. Related Python and neural-network
experiments are included alongside the MATLAB code and research results.

## Getting oriented

Start with the folder for the model you want to explore.
The modeling, validation, and results folders contain different parts
of the research workflow.

The MATLAB scripts and Python experiments are separate pieces of
research code; there is no single application entry point.

## Research reference

The work draws on research into the asymptotic analysis of resonances
of small high-contrast scatterers:
